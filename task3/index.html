Task 3. Three layouts, one markup

The article markup below never changes. Only which of the three radio buttons is checked changes — that single piece of state is what switches the container between grid, list and magazine mode. No JavaScript is used (the assignment rules forbid it); the CSS :checked selector does the job a class-toggle script would otherwise do.

Lead story: a very long headline that has to survive every layout

This is the lead item. In magazine mode it is given more space than the others; in grid and list mode it behaves exactly like every other card, which is the whole point of sharing one markup.
